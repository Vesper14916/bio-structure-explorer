## Design gaps

- **Per-part transform convention:** `spec.parts[partId].transform` (`{ o, R }`) is applied in the actor's local frame (before the actor's world transform) across that part's L0 mesh, L1 beads, and L2 atoms/bonds, keeping release offsets independent of actor world orientation.
- **Crowder `transforms` buffer layout:** `setCrowd([{ assetId, asset?, transforms: Float32Array }])` expects 16 column-major Three.js `Matrix4` floats per instance (matching `THREE.Matrix4.toArray(buf, i * 16)` and `InstancedMesh.instanceMatrix`), which ST8 `R3-R4` (`js/scene/crowd.js`) can emit directly without per-frame conversion.
- **Exact `> 0` cubic tail threshold in `FxLayer`:** `pulseWeight(f)` and `gtpOpacity(f)` return exact `0` at `f <= 0` and `f >= 1`; `FxLayer.update` checks `w > 0` and `op > 0` so `easeInOutCubic` fades complete at exact 400 ms / 1400 ms without premature cutoff.
