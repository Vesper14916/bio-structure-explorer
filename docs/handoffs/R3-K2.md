# Handoff R3-K2: Free chains, terminator hairpin, and peptide on a path (Stage ST5)

Branch: `r3/k2` (base `50716d1` = `r3-w1` + `DEC-011`). Spec: `PLAN.md` §§5.1, 8.3, 10 (R3-K2); `docs/CONTRACTS.md` §7.4; `docs/DECISIONS.md` `DEC-005`, `DEC-012`.

## Changed files

- `js/kin/chain.js`: Replaced W0 stub with `buildFreeChain(controlPoints, opts = {})`, `poseFreeChain(chain, count, t, outFrames)`, and deterministic tail-generator helper `generateTailControlPoints`. Implements centripetal Catmull–Rom splines (`alpha = 0.5`), 512-sample arc-length tables, rotation-minimising frames, A-form single-strand stepping (`rise 2.81 Å`, `twist 32.73°`), `mulberry32(seed ^ hash(chainId))` control-point generation (20-nt spacing, ≤ 35° turn), and sinusoidal normal sway (`6 Å · sin(2π(t/7 + φ_k))`) smoothly damped to 0 within 30 Å of anchors. Zero DOM / Three.js imports.
- `js/kin/hairpin.js`: Replaced W0 stub with `poseHairpin(anchor, foldProgress, outFrames, opts = {})` and progressive folding helper `hairpinPairFold`. Builds Construct v3's 8-bp A-form stem (`HELIX_A`, `GGCCGCUU` / `AAGCGGCC`) + 4-nt `GAAA` tetraloop (20 nt) posed by `anchor`, with apical-to-closing progressive folding and canonical Watson–Crick H-bond geometry at full fold. Zero DOM / Three.js imports.
- `js/kin/peptide-path.js`: Replaced W0 stub with `posePeptideOnPath(codes3, tunnelPath, freePath, releaseProgress, outGroup)`. Precomputes per-residue local frames from S1's `buildPeptide` across all 20 amino acids + `FME`/`fMet`, concatenates `tunnelPath` + `freePath` with arc-length table and RMF, places residue `k` (`k = 0` C-terminus at `ptc`) at `k · 3.40 + releaseOffset` Å, and writes reusable `AtomGroup` buffers compatible with `AtomGroupLayer`. Zero DOM / Three.js imports.
- `tests/kin-chain.test.mjs`: 11 unit tests verifying zero DOM/Three.js imports, free-chain spacing (`2.81 ± 0.05 Å`) & `O3′–P ≤ 1.9 Å` across 179-nt curved mRNA, 30 Å anchor damping, hairpin 9-nt clearance rule & full-fold `2.7–3.1 Å` Watson–Crick H-bonds, and 40-aa Construct v3 peptide on real `ribosome-70s` `paths.tunnel` satisfying `C(i)–N(i+1) ∈ 1.33 ± 0.25 Å` across `releaseProgress = 0..1` with buffer reuse.
- `docs/evidence/r3/K2/`: 4 screenshots at 1440×900 `deviceScaleFactor: 2` JPEG q90 (`free-chain-mrna.jpg`, `terminator-hairpin.jpg`, `peptide-tunnel-ribosome.jpg`, `peptide-released-closeup.jpg`), visually inspected.
- `docs/handoffs/R3-K2.md`: This handoff.
