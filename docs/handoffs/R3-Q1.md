# Handoff R3-Q1: Standalone assets and gates (Stage ST4)

Branch: `r3/q1` (branched from `r3-st3`).

## Changed files

- `tools/build-standalone.mjs`: reads `assets/manifest.json` and every listed asset JSON, checks `raw.id === entry.id`, inlines `{ __manifest__, [id]: raw }` into `window.__HELIX_ASSETS__` with HTML-safe JSON escaping (`<` -> `\u003c`, plus `\u2028` / `\u2029`), adds the data-URI favicon from `index.html`, and logs exact output bytes / KB / MB and inlined asset count.
- `tests/smoke.browser.mjs`:
  - Preserves all existing 6-mode and Express v1 scrub checks on `/index.html` and `/dist/helix-standalone.html`.
  - Adds `?mode=express&scene=v2` verification on `/index.html?mode=express&scene=v2` and `/dist/helix-standalone.html?mode=express&scene=v2` (canvas check, zero console errors, zero page errors, zero HTTP >= 400, zero external requests).
  - Adds offline verification on `/dist/helix-standalone.html?mode=express&scene=v2` using `page.route(/^https?:\/\//, ...)` to block all other-origin requests and all HTTP/HTTPS subresource fetches after the initial document load, verifying `window.__HELIX_ASSETS__` and `window.__HELIX_ASSETS__.__manifest__` are populated and `loadAssets(['ribosome-70s', 'trna-init', 'trna-aa', 'rnap-ec', 'rnap-holo'])` from `js/assets/registry.js` decodes all 5 assets with zero network fetches.
  - Adds failing module path reporting via `requestfailed`, HTTP >= 400 `response`, `pageerror`, `console.error`, CDP `Runtime.exceptionThrown` (resolving both HTTP URLs and standalone importmap `data:` URLs back to `js/...`), and wrapped dynamic `import()` checks over all non-vendor `js/**/*.js` modules with root-cause dependency filtering.
- `tests/asset-budgets.test.mjs` (new): `node:test` suite reading `assets/manifest.json`, validating every committed asset with `validateAsset(raw)` (zero errors), and checking `PLAN.md` §7.5 budgets for `ribosome-70s`, `trna-*`, factors (`rf1`, `ef-tu`, `ef-g`, `if1`, `if2`, `if3`, `nusg`), RNAP (`rnap-ec`, `rnap-holo`), total manifest assets (<= 3,000,000 bytes), and `dist/helix-standalone.html` when present on disk (<= 7,500,000 bytes).
- `docs/handoffs/R3-Q1.md` (new): this handoff record.
- `package.json`: unchanged (existing `test` script `node --test tests/*.test.mjs` automatically runs `tests/asset-budgets.test.mjs`, and `build:standalone` / `smoke` scripts are already present).
- `dist/helix-standalone.html`: built and verified locally, then reverted with `git checkout -- dist/helix-standalone.html` before commit because the Chief owns `dist/`.
