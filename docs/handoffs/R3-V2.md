# Handoff — R3-V2 (Visual evidence sweep)

Stage: ST8 · Branch: `claude/project-thread-weimhy`

## Changed files

- `tools/evidence/sweep.mjs` — drives the real app (`index.html?mode=express&scene=v2`) in headless Chromium with software GL, camera `Auto`, quality `medium`. For each chapter it takes start (2 %), middle (50 %) and end (98 %) frames at a desktop (1440 × 900) and an iPhone 13 profile, checks that the scene state at the shot time matches `stateAt`, records the caption, and builds one contact sheet per mode and device plus `index.md`. Options: `--mode`, `--chapters`, `--dsf`, `--devices`, `--shots`, `--out`. Exit 0 only when every shot was taken with no console or page error.
- `docs/evidence/r3/sweep/` — **reduced run**: `sequential/desktop/chNN-<id>-mid.jpg` (16 frames, dsf 1), `sequential-desktop-contact.jpg`, `index.md` with t and caption, `manifest.json`.

Command used: `node tools/evidence/sweep.mjs --mode sequential --chapters 1-16 --devices desktop --shots mid`
Result: `shots=16 failed=0 console_errors=0 page_errors=0`.
