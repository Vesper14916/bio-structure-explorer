## Requests
1. **Tunnel target (deviation from `PLAN.md` §7.4 step 2).** The §7.4 target, the voxel nearest the uL23/uL29 Cα centroid, lies on the subunit surface about 45 Å past the tunnel mouth, so the full route is 145.9 Å and fails the 75–110 Å gate. The §13 fallback (straight line from `ptc`) was rejected because it passes 0.16 Å from rRNA, so a peptide drawn on it would cross the 50S. The shipped path is the same Dijkstra route truncated at its first solvent-side point after 60 Å (the §7.4 solvent-side test with exact clearances). It passes both gates. Please record this in `docs/DECISIONS.md`.
2. **7PJV superposition (affects A3, EF-G, in ST5).** 7PJV is a rotated, hybrid-state ribosome. The §7.3 rule (16S + 23S) keeps only 12.9 % of the matched P atoms and passes the 1.5 Å gate only because of that trimming. Measured: 23S only 0.78 Å (2,600 of 2,749); 16S only 1.08 Å (1,158 of 1,519). Proposal: fit EF-G on 23S only, and add a minimum kept fraction of 50 % to the superposition gate. For this asset the rule was applied as written, so `siteAP` (5.1 Å) and `sitePE` (6.1 Å) fail the 4.0 Å condition and are omitted (pre-approved: direct interpolation between classic sites). Note that a 16S-only fit would put both hybrid anticodons within 1.1 Å and pass; changing the rule is the Chief's decision.
3. **Superposition matching by author numbering.** 7ST2 numbers its 16S with label_seq_id = author − 1, so matching by label_seq_id (as `tools/lib/match.mjs` does) misaligns by one nucleotide. The ribosome recipe matches rRNA by author number and residue name. A3 and A4 should do the same; consider adding an author-number option to `match.mjs`.
