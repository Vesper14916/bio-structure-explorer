# Handoff R3-R1: Detail sphere and atom groups (Stage ST4)

Branch: `r3/r1` (branched from `r3-st3` / `41c44f6`). Spec: `PLAN.md` §4.3, §4.4, §4.5, §10 (R3-R1); `docs/CONTRACTS.md` §6.4, §7.5.

## Changed files

- `js/render/molecule.js`: Added `DETAIL_FADE_BAND` (12 Å) and `computeDetailWeight(dx, dy, dz, radius)` (`0` everywhere when `radius <= 0`; `1` inside `radius`; `0` beyond `radius + 12` Å; `1 - smoothstep(radius, radius + 12, d)` inside `[radius, radius + 12]`). Added `setDetailFocus(focus)` on `MoleculeLayer`, caching per-nucleotide `C1'` reference atoms (falling back to nucleotide frame origin or first atom). When `detailFocus` is set, atom spheres and covalent half-bonds scale by `nucScale * weight` (hidden at `<= 0.001`), and H-bonds draw only for pairs with `max(weightA, weightB) > 0.05` (hidden at `radius <= 0`). When `detailFocus === null`, the existing rendering path is unchanged.
- `js/render/cartoon.js`: Added `setDetailFocus(focus)` on `CartoonLayer`, computing the complement weight `1 - weight` per nucleotide using `computeDetailWeight` and applying `nucScale * (1 - weight)` to backbone tube radii, base slabs, and `C1'` connectors (hidden at `<= 0.001`). When `detailFocus === null`, behavior is unchanged.
- `js/render/atom-groups.js`: Replaced the W0 stub with `AtomGroupLayer` (`.group`, `setGroups(groups, style)`, `setDetailFocus(focus)`, `setStyle(style)`, `setTier(tier)`, `update()`, `clear()`, `dispose()`). Uses `MoleculeLayer` material parameters (`atomMat` roughness `0.32` / metalness `0.06`; `bondMat` `0.42` / `0.05`; `BALL_SCALE 0.3`; `BOND_RADIUS 0.17`; `PEPTIDE_BOND_RADIUS 0.42`). Implements `strand` (peptide backbone `0xff7a45`, side chains lightened 35% toward `0xffffff`; non-peptide `group.color` or element fallback), `codon` (`AMINO_ACIDS` per-residue lookup including `FME`/`fMet`), and `element` (`ELEMENT_INFO` + §4.3 tokens `S 0xe6c84a`, `Mg 0x7dff7a`, `Zn 0x8f9cc9`, other `0xb0b8c8`). Supports peptide Cα cartoon tube (`0.42` Å radius) + Cα beads (`0.85` Å radius) smoothly cross-faded with ball-and-stick across the 12 Å band, explicit `group.detail` overrides (`'ballstick' | 'cartoon' | 'auto'`), translucent per-group materials when `opacity < 1`, buffer reuse, and GPU disposal on removal/replacement/`dispose()`.
- `js/render/viewer.js`: Added `setDetailFocus(focus)` and `setAtomGroups(groups)` on `Viewer` and its public API, with lazy `AtomGroupLayer` allocation on first non-empty group list so legacy modes incur zero extra scene/material allocation. Coexists `CartoonLayer` with `MoleculeLayer` whenever `detailFocus !== null` while preserving exact existing representation switching when `detailFocus === null`. Wired `AtomGroupLayer` into `setTier`, `recolor`, `updateGeometry`, `tick`, `setStyle`, and `dispose`.
- `tests/render-detail.browser.mjs`: Browser verification and visual regression suite covering (1) 248-bp duplex + 40-residue peptide + ATP detail sphere, focus shifts, `radius: 0` cartoon-only, `strand`/`codon`/`element` colour schemes, `readPixels` diffs, GPU geometry disposal across clear/restore cycles, and 1440×900 2× JPEG q90 screenshots; (2) 248-bp duplex + 179-nt RNA (`675 nt`, `13965 atoms`) software-WebGL performance/stability check at `quality: 'high'`; (3) pixel-by-pixel visual regression comparing `r3-st3` vs current branch across Explore, Pairs, Melt, Copy, and X-ray (`<= 0.5%` threshold).
- `docs/evidence/r3/R1/`: 5 screenshots at 1440×900, `deviceScaleFactor: 2`, JPEG quality 90 (`detail-center-r30.jpg`, `detail-shifted-r30.jpg`, `detail-radius0-cartoon.jpg`, `detail-codon-scheme.jpg`, `detail-element-scheme.jpg`).
- `docs/handoffs/R3-R1.md`: This handoff.

## Design gaps

- **Peptide cartoon Cα bead radius:** `PLAN.md` §4.4 specifies a peptide cartoon Cα tube of radius `PEPTIDE_BOND_RADIUS` (`0.42` Å) with Cα spheres/beads, without naming a bead radius. `AtomGroupLayer` uses `CA_BEAD_RADIUS = 0.85` Å (≈ 2× the tube radius, matching visual legibility against the nucleic-acid backbone tube in `detail-center-r30.jpg` and `detail-radius0-cartoon.jpg`).
- **Peptide cartoon colour under `element` scheme:** Because the cartoon trace connects Cα atoms, `element` scheme colours the Cα tube and Cα beads with `ELEMENT_INFO.C.color` (`0x9eb2cc`), as visible in `detail-element-scheme.jpg`.
- **Single-residue peptide cartoon:** When a peptide has fewer than 2 residues (`residues.length < 2`), `AtomGroupLayer` draws the Cα bead without building a degenerate 0-length tube.
